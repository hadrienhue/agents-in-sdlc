# Page de vente – version Google Sites

`page-vente-trousse.html` est la page 3 du tunnel, adaptée pour être intégrée dans Google Sites.

## Mise en ligne (compte bioconnect.medical@gmail.com)

1. Connectez-vous au compte, puis ouvrez https://sites.google.com et créez un site vierge (« + »).
2. Dans le panneau de droite, choisissez **Insérer → Intégrer → Code d'intégration**, collez tout le fichier, puis cliquez sur **Suivant → Insérer**.
3. Étirez le bloc à **toute la largeur** de la page, puis **vers le bas** jusqu'à ce que toute la page soit visible (environ 7 200 px de haut sur ordinateur).
4. Masquez l'en-tête du site Google (survol de la bannière → supprimer) pour ne pas avoir deux en-têtes.
5. Cliquez sur **Publier**, choisissez l'adresse, puis vérifiez la page publiée sur ordinateur **et sur téléphone**.

## Différences avec la version systeme.io

- Le menu de navigation et la barre « Commander » fixée en bas sont retirés : dans un bloc intégré Google Sites, ils ne font pas défiler la page.
- Tous les boutons « Commander » mènent directement à `LIEN_COMMANDE` et s'ouvrent dans un nouvel onglet.

## Limite connue

Google Sites donne au bloc intégré une **hauteur fixe**. Sur téléphone, la page fait environ 11 000 px contre environ 7 200 px sur ordinateur : un bloc réglé pour l'ordinateur risque d'être coupé sur mobile. Vérifiez sur téléphone et agrandissez le bloc si besoin.

## À remplacer avant de coller

`LIEN_COMMANDE`, `XX,XX €`, `CONTACT_EMAIL`, `LIEN_FACEBOOK`, `LIEN_INSTAGRAM`, `LIEN_LINKEDIN`, `LIEN_MENTIONS_LEGALES`, `LIEN_CONFIDENTIALITE`, `LIEN_CGV`, `IMG_FAMILLE`.
